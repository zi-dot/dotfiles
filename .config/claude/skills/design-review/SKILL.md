# Design Review Skill

Codex MCPを使用して機能設計・アーキテクチャのレビューを実行するスキルです。

## Instructions

ユーザーが設計レビューを依頼した場合:

1. レビュー対象を特定する
   - 設計ドキュメント、コード構造、またはアーキテクチャ図を確認
   - 対象が不明な場合はユーザーに確認

## レビュー観点
- SOLID原則: 単一責任、開放閉鎖、リスコフ置換、インターフェース分離、依存性逆転
- 設計パターン: 適切なパターンの使用、アンチパターンの有無
- 責務分離: レイヤー構造、モジュール間の依存関係
- 拡張性: 将来の変更に対する柔軟性
- テスタビリティ: テストしやすい設計か
- 複雑性: 過度な抽象化、不要な複雑さ

3. Codex MCPのパラメータ設定
   - `sandbox`: "read-only" を使用
   - `cwd`: レビュー対象のプロジェクトディレクトリ

4. レビュー結果をユーザーに報告
