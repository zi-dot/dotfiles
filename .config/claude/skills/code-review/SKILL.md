# Code Review Skill

Codex MCPを使用してコードレビューを実行するスキルです。

## Instructions

ユーザーがコードレビューを依頼した場合:

1. レビュー対象を特定する
   - 特定のファイル、ディレクトリ、または変更内容（git diff）を確認
   - 対象が不明な場合はユーザーに確認

2. Codex MCPの `codex` ツールを使用してレビューを実行
   - 以下のプロンプトテンプレートを使用:

```
以下のコードをレビューしてください。

## レビュー観点
- コード品質: 可読性、保守性、命名規則
- バグ: 潜在的なバグ、エッジケース、エラーハンドリング
- セキュリティ: OWASP Top 10、入力検証、認証/認可
- パフォーマンス: 非効率なアルゴリズム、N+1問題、メモリリーク
- テスト: テストカバレッジ、テストの質

## レビュー対象
{対象のコードまたはファイルパス}

## 出力形式
以下の形式で結果を出力してください:
### 重要度: 高
- [問題の説明と修正案]

### 重要度: 中
- [問題の説明と修正案]

### 重要度: 低
- [問題の説明と修正案]

### 良い点
- [良い実装や設計]
```

3. Codex MCPのパラメータ設定
   - `sandbox`: "read-only" を使用（コードを読むだけなので）
   - `cwd`: レビュー対象のプロジェクトディレクトリ

4. レビュー結果をユーザーに報告
   - 重要度別に整理して報告
   - 必要に応じて具体的な修正コードを提示
